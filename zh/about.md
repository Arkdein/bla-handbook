## 我们是谁 {#who-we-are}

立化中学创办于1956年，是政府开办的第一所华文中学，并于1979年成为首批特选中学之一。双文化课程（BSP）自2000年代开办以来，一直是我校的特色课程之一。

双文化领袖学研中心成立于2017年，旨在整合现有的双文化课程活动，并加强我校双文化人才的遴选机制与培养计划。会员为中三至高二学生，包括修读双文化课程、文学或H2华文科目的学生，以及中学时修读双文化课程或文学的高中生。

### 我们的使命 {#our-mission}

> 为新加坡培养精通华族语言文化、深植华族价值观、具备环球视野的双文化领袖。

### 课程展望 {#our-aspiration}

> 发掘学生的双语潜能并开拓他们的视野，为新加坡培养对东西方文化有学习热忱的双文化人才。

## 我们所说的“双文化” {#what-we-mean-by-bicultural}

双文化不只是掌握两种语言。立化从三个层面理解双文化：

| 层面 | 对BLA会员的意义 |
|:--|:--|
| **新加坡华族文化** | 认同华族价值观，珍惜自己的文化根源；同时认识到新加坡华人与中国大陆、香港、台湾及其他地区华人的不同经验。 |
| **当代中国** | 深入了解中国的社会文化与当代发展，同时立足新加坡，思考如何运用所学，为新加坡与中国建立联系。 |
| **东方与西方** | 了解东西方文化，取两者之长，在不同文化之间担当桥梁。 |

## PAC框架 {#the-pac-framework}

双文化领袖须具备以下三方面的知识与技能，缺一不可。BLA的大多数活动都至少围绕其中一项设计。

<span class="bla-pac bla-pac-p">P</span> **中英语表达能力** Proficiency in Chinese and English
: 双文化领袖必须能以两种语言清楚表达。BLA在课堂以外为会员提供说、写和发表华文的平台。

<span class="bla-pac bla-pac-a">A</span> **华族历史文化鉴赏能力** Appreciation of Chinese History, Culture and Values
: 要与中国同侪进行有意义的交流，并清楚自己在世界上的立足点，会员须熟悉华族历史文化，并深植华族价值观。

<span class="bla-pac bla-pac-c">C</span> **跨文化技能与环球意识** Cross-Cultural Skills and Global Awareness
: 通过论坛和学习之旅，会员学会在国际大局中审视新加坡与中国内外的发展动态，并能跨越文化差异与人合作。

### 活动与PAC的对应 {#how-our-programme-maps-to-pac}

| 活动 | PAC | 内容 |
|:--|:--|:--|
| Academy Time（AT） | <span class="bla-pac bla-pac-p">P</span> <span class="bla-pac bla-pac-a">A</span> <span class="bla-pac bla-pac-c">C</span> | 由会员策划和主持的分享、工作坊和讲座。每次活动的提案都须说明对应PAC的哪一项。 |
| 研习项目与BLA研讨会（旗舰活动） | <span class="bla-pac bla-pac-p">P</span> <span class="bla-pac bla-pac-a">A</span> <span class="bla-pac bla-pac-c">C</span> | 会员完成独立研习项目，以双文化视角深入分析中西文化及新中政治、经济和社会等课题，并向同侪及特邀专家学者发表。 |
| 透视中国学生双语论坛（旗舰活动） | <span class="bla-pac bla-pac-c">C</span> | 与通商中国联办的双语论坛。具东西方视角的嘉宾与立化及他校学生一同探讨当下中国热点课题。 |
| 讲座@立化 | <span class="bla-pac bla-pac-a">A</span> <span class="bla-pac bla-pac-c">C</span> | 特邀讲者谈华族文化、当代中国及东西方课题。 |
| 学习之旅 | <span class="bla-pac bla-pac-c">C</span> | 参观机构，包括与中国有业务往来的企业。 |
| BSP校友分享会 | <span class="bla-pac bla-pac-c">C</span> | 双文化课程校友分享离开立化后的发展。晚上线上进行。 |
| 农历新年及中秋节庆祝活动 | <span class="bla-pac bla-pac-a">A</span> | BLA代表学校为全校筹办的节庆活动。 |
| 淑群小学社区服务 | — | 服务社区，体现学校的价值观。 |

### 工作组 {#our-divisions}

BSP理事会成员各自加入一个工作组，通过BLA的多媒体平台，与会员和全校同学分享所学。

| 工作组 | 重点 |
|:--|:--|
| **时事组** | 关注本地新闻和国际大事（包括中国与美国的发展），以时事分析、短篇专题等方式深入浅出地介绍。 |
| **文化组** | 普及历史与思想、潮流与习俗、文字与语言三方面的文化常识，激发同学对中英双语、双文化及新加坡本土文化的兴趣。 |
| **文艺组** | 通过文艺作品推广中华文化及新加坡华族文化；也是组员创作与分享的平台。 |

## BLA如何体现学校的愿景、使命与价值观 {#how-bla-serves-the-schools-vision-mission-and-values}

BLA是立化中学实践其愿景、使命与价值观的途径之一。会员应清楚两者之间的联系。

### 愿景：为国家培育卓越领袖 {#vision}

学校的愿景与BLA的使命方向一致：培养**为国家**服务的领袖。BLA的贡献在于双文化的优势。新加坡需要既了解中国、又能与西方沟通的人才，为国家在两者之间搭建桥梁。

### 使命 {#mission}

> 培养品行端正，慎思明辨，融贯中西，具环球视野的国家栋梁
>
> To nurture thinkers, leaders and achievers with good character, bicultural acumen and global perspective

| 学校使命 | 在BLA的体现 |
|:--|:--|
| **慎思明辨** | 以双文化视角分析文化、政治、经济与社会课题的研习项目；时事组的时事分析。 |
| **国家栋梁** | 领导：执委与BSP理事会、筹办全校节庆活动、由会员主持AT。成就：在BLA研讨会上向同侪和专家学者发表研究成果；代表学校出席教育部主办的BSP研讨会。 |
| **品行端正** | 诚实出席、对团队负责、服务他人（见下文价值观）。 |
| **融贯中西** | PAC框架中的<span class="bla-pac bla-pac-p">P</span>和<span class="bla-pac bla-pac-a">A</span>。 |
| **具环球视野** | PAC框架中的<span class="bla-pac bla-pac-c">C</span>：透视中国学生双语论坛、学习之旅和校友分享会。 |

### 价值观 {#values}

| 学校价值观 | 在BLA的体现 |
|:--|:--|
| **追求卓越** | 研习项目达到学术水准，并向包括学者在内的听众发表。 |
| **奋发图强** | 坚持完成为期一年的研习项目；在课业和其他CCA之外，履行对BLA的承诺。 |
| **以人为本** | 为全校筹办节庆活动，到淑群小学服务。会员经常缺席时，我们先了解原因，再作其他处理。 |
| **自立自发** | 会员自行提出并主持AT和各项活动；执委与老师一同管理学研中心。 |

### 校训：立德立功 · 化愚化顽 {#motto}

*Upholding Virtues, Contributing to Society.* 双文化教育的意义在于服务他人。BLA为全校筹办农历新年和中秋节活动，并把透视中国学生双语论坛开放给其他中学、初级学院及大专学府的学生。
