## 会员义务 {#your-commitments}

每位会员都须：

- 每年出席**至少70%**的BLA活动；
- 出席两项**旗舰活动**：透视中国学生双语论坛和BLA研讨会（紧急事故除外）。

视入会方式而定，你还须：

| 你是…… | 另须 |
|:--|:--|
| 中学部修读双文化课程或文学的学生 | 每年完成一项研习项目。 |
| 高中部会员 | 完成研习项目，或以AU积分替代。 |
| BSP理事会成员 | 加入一个工作组，每年至少参与筹办一次BLA活动。 |

**高二会员**第二学期无需出席AT，但保留会员身份至毕业。

依据：SOP 1（适用范围）及SOP 6
{: .bla-source }

## 活动通知 {#how-youll-hear-about-activities}

活动通知会在**BLA公告群**发出，并附上请假单：

- **AT：**活动前**2周**；
- **旗舰活动**，以及需要向课程或其他CCA请假的活动：活动前**4周**。

通知列明日期、时间、地点和议程。活动前一天会再发提醒。全年日期见[重要日期](key-dates.md)。

依据：SOP 1
{: .bla-source }

## 无法出席？请假申请 {#cant-attend-applying-for-an-excusal}

如无法出席，或会迟到、早退，请在截止日期前通过**该活动的请假单**申请。未经批准而缺席者，一律作无故缺席论。

### 截止日期 {#deadlines}

| 活动 | 请假单截止 |
|:--|:--|
| AT | 活动前10天的星期五晚上11时59分 |
| 旗舰活动 | 活动前3周 |

AT前约一周（旗舰活动前2周），审批结果会在公告群公布。申请不获批准者，必须出席。

### 请假单怎么填 {#what-to-write}

1. 中英文姓名和班级。
2. 无法出席、迟到还是早退，以及到达或离开的时间。
3. **具体原因**：写明活动名称、时间及你的角色，例如“NSG半决赛，正选队员”。只写“CCA”或“Lesson”的申请会退回补充。
4. 相关活动负责老师的姓名与电邮。

{: .important_zh }
**截止后只接受紧急情况。**如生病或家中有急事，最迟须在活动当天通知组长或执委，并在事后补交证明。

### 一般审批结果 {#what-is-usually-approved}

以下整理自老师在2025–2026年的实际裁定。旗舰活动的审批标准从严。

| 原因 | 一般裁定 |
|:--|:--|
| 学校考试、口试、计时练习 | 批准 |
| 学校安排的课程、讲座、补课 | 批准；下课后须到场 |
| 代表学校或国家参赛、国家队训练 | 批准 |
| 就医、病假 | 批准 |
| 学校或教育部安排的课程（如第三语文） | 批准 |
| 在其他CCA担任关键职务（如执委、教练） | 视情况而定 |
| 与其他学研中心的活动撞期 | 首次批准；再次撞期时须出席BLA |
| 其他CCA的一般训练 | AT：视情况而定；旗舰活动：不批准 |
| 国庆庆典等大型活动 | 视情况而定：你是否不可取代？ |
| 自愿性质的义工活动 | 不批准 |
| 私人补习、私人课程 | 不批准 |
| 活动开始后不久即早退 | 不批准；若另有正当理由，请申请全程请假 |

<details class="bla-more" markdown="1">
<summary>因固定安排而长期无法出席AT</summary>

如果你因固定的课程或训练（例如每周一的O水准音乐课）全年无法出席AT，请告知执委。执委会安排其他参与方式，例如在Google Classroom观看AT简报并填写心得，或参与筹办活动。

</details>

依据：SOP 2

## 为BLA活动向课程或其他CCA请假 {#missing-lessons-or-another-cca-for-bla}

有些活动（如透视中国学生双语论坛或彩排）在放学前开始。遇到这种情况：

1. **登记所有撞期**：在同一份请假单的“课程/CCA请假”分页，于活动前3周登记受影响的课程或CCA、时间，以及负责老师的姓名与电邮。每项课程填写一行。
2. **洪老师电邮通知**每位相关老师（活动前2周）。
3. **未经老师同意，不得自行缺课。**老师不批准时，照常上课；该次缺席BLA记为获准请假。
4. **自行补上**所缺的课业。

**撞期时的优先顺序：**学校考试 → 代表学校参赛 → BLA旗舰活动 → 学校正课 → 其他CCA常规训练。

依据：SOP 3
{: .bla-source }

## 出席记录 {#attendance}

- 每次活动开始时，由班代表**当场点名**。不再使用QR码签到链接。
- 迟到者会被记下到达时间。

| 代码 | 意思 |
|:--|:--|
| Y | 出席 |
| L | 迟到 |
| VR | 获准请假 |
| A | 无故缺席 |

### 出席率的计算 {#how-your-attendance-rate-is-worked-out}

获准请假不计入分母：

> 出席率 = 出席次数（Y + L）÷（活动总数 − 获准请假次数）

**例子：**全年共20次活动。你获准请假2次，无故缺席3次，其余15次都出席。出席率 = 15 ÷（20 − 2）= 83%。

出席率在第四学段核算，检查是否达到70%。

依据：SOP 4
{: .bla-source }

## 学校CCA记录 {#what-counts-for-your-school-cca-record}

只有两类参与记入**学校CCA记录**：

- **执委职位**（主席、副主席、工作组组长）及任期（每年7月至翌年7月）；
- **农历新年或中秋节庆祝活动**的筹委职位（BLA代表学校为全校举办）。

其他BLA参与，例如筹办透视中国学生双语论坛、研讨会、迎新会或交接仪式，主持AT，以及研习项目，都记入**BLA portfolio**。老师在遴选执委、提名EAGLES奖和撰写推荐信时会参考这份记录。

依据：SOP 5
{: .bla-source }

## 会员资格 {#membership}

### 入会方式 {#who-joins}

| 你是…… | 入会方式 |
|:--|:--|
| 中学部修读双文化课程的学生 | 必须入会 |
| 中学部修读文学的学生 | 自选入会 |
| 高中部修读H2华文与文学、翻译或中国通识的学生 | 申请 |
| 中学时修读双文化课程或文学的高中生 | 申请 |
| BSP奖学金得主 | 加入BSP理事会及一个工作组 |
| 其他会员 | 可申请加入BSP理事会 |

**高一学生**在第一学段的JC Primer Day认识BLA，并填写申请表格。所有新会员（中三与高一）在第二学段的迎新会上一起入会。

### 工作组 {#divisions}

迎新会后2周内，BSP理事会成员选择工作组：**时事组**、**文化组**或**文艺组**。在原工作组满两年后可申请调换，须经负责老师（TIC）批准。工作组简介见[关于BLA](about.md#our-divisions)。

### CCA籍属 {#bla-as-your-cca}

- **中学部：**BLA为第二CCA。
- **高中部：**可以BLA为第一CCA。
- **高中部BSP奖学金得主：**必须以BLA为第一CCA。若在另一个CCA担任关键职务，经两位负责老师商定后，可改以BLA为第二CCA。

### 退会 {#leaving}

必须入会的会员不得退会。其他会员可在学年结束时申请退会，须经负责老师批准；学年中途退会仅限特殊情况。

依据：SOP 6
{: .bla-source }

## 无故缺席与违纪 {#if-you-miss-activities-without-an-excuse}

无故缺席、未作交代而没有完成分配的工作，或长期不回复组长、筹委的信息，都算**违纪**。违纪次数按学年累计，每年1月归零。

| 违纪 | 处理 |
|:--|:--|
| 第一次 | 组长（或副主席〈活动与行政〉）了解原因并口头警告。 |
| 第二次 | 与主席及一位老师面谈；正式警告，并安排补偿任务（如观看AT录影并提交心得）。 |
| 第三次 | 与洪老师面谈；通知家长及班主任/公民导师。 |
| 第四次 | 撤销执委、工作组组长或筹委职位；当年不得参选执委，也不获EAGLES提名；再次通知家长。**保留会员身份。** |

- **出席作弊**（替他人签到、把签到链接转发给缺席者）：双方直接从第二级开始处理。
- **严重行为问题**（如不诚实、欺凌）由学校纪律程序处理，不属BLA处理范围。
- **年终出席率低于70%：**须与洪老师面谈，当年不得参选执委，也不获EAGLES提名。

{: .tip_zh }
**有困难，请告诉我们。**经常缺席有时是因为课业或其他事情带来压力。若是如此，执委会告知洪老师；洪老师会联系你的班主任或学校辅导员，上述处理也会暂停。

依据：SOP 7
{: .bla-source }

## 成为执委 {#becoming-exco}

新一届执委于第二学段选出，在七月的第一个AT举行交接仪式后接任，任期一年。

**参选资格：**高一会员；当年未被撤销职位，且上一年出席率不低于70%。已在其他学研中心担任主席或副主席者，不宜兼任BLA主席或副主席。

| 时间 | 事项 |
|:--|:--|
| 4月中旬 | 卸任主席向高一会员发出意愿表格。 |
| 4月底 | 表格截止；老师与组长也可推荐人选。 |
| 5月第一周 | 由卸任执委与老师进行小组面试。 |
| 一周后 | 老师确定执委人选，私下通知结果。 |
| 再一周后 | 入选者制作不超过3分钟的竞选视频，阐述对BLA的愿景。 |
| 5月中旬 | 全体会员线上观看视频并投票选出主席。 |
| 5月下旬 | 公布新一届执委名单。 |
| 7月第一个AT | 举行交接仪式；卸任执委转为咨询团队，至12月为止。 |

面试采用五项标准：沟通能力、团队协作、前瞻性领导、行动管理、应变能力。

依据：SOP 9
{: .bla-source }

## 个人资料 {#your-personal-data}

- 请假单只收集必要资料：姓名、班级、原因，以及负责老师的姓名与电邮。就医只需写“就医/病假”，不必写病情。
- 含个人资料的文件只开放给指定人士，不开放给“任何持有链接者”。
- 公告群只公布审批结果（批准/不批准），不公开请假原因。

依据：SOP 8
{: .bla-source }
